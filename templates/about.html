Parkinson's Disease Prediction System

Parkinson AI is a machine learning based healthcare support system designed to analyze biomedical voice measurements and provide a prediction related to Parkinson's disease.

The system uses a trained Random Forest Classifier to analyze the input measurements and generate a prediction with a confidence score.

Technology Used

Machine Learning

Random Forest Classifier is used to classify biomedical voice measurements and generate prediction results.

Flask

Flask provides the web application framework that connects the prediction model with the user interface.

Python

Python is used for data processing, machine learning, model prediction, and application development.

How It Works

01

Enter Measurements

Enter the required biomedical voice measurements in the prediction form.

02

Data Processing

The input data is processed using the trained preprocessing objects.

03

AI Prediction

The Random Forest model analyzes the measurements and generates a prediction.

04

View Result

The system displays the prediction and confidence percentage.

Important Information

This system is developed as a machine learning project and is intended for educational and decision-support purposes. It should not be used as a substitute for professional medical diagnosis or treatment.
